# I2C周辺デバイス

## I2Cバス構成

### メインI2Cバス（内部専用）
- **SDA**: GPIO7
- **SCL**: GPIO8
- **プルアップ**: 基板上に実装
- **用途**: 製品内部の周辺デバイス通信専用

## 接続デバイス一覧

### 1. ES8311 オーディオコーデック
- **I2Cアドレス**: 0x18 (7-bit)
- **用途**: オーディオ入出力制御
- **インターフェース**:
  - I2C: GPIO7 (SDA), GPIO8 (SCL)
  - I2S: GPIO9-13, GPIO48
  - パワーアンプ制御: GPIO11 (PA_CTRL)

### 2. GT911 タッチコントローラ
- **I2Cアドレス**: 0x5D または 0x14 (設定により変更可能)
- **用途**: タッチパネル入力
- **信号線**:
  - I2C: GPIO7 (SDA), GPIO8 (SCL)
  - 割り込み: GPIO21 (TOUCH_INT)
  - リセット: GPIO22 (TOUCH_RST)

### 3. DS3231M RTC (リアルタイムクロック)
- **型番**: DS3231M (Maxim Integrated)
- **I2Cアドレス**: 0x68 (7-bit)
- **用途**: 正確な時刻管理、アラーム機能
- **特徴**:
  - 温度補償付き水晶発振器 (TCXO)
  - 年/月/日/時/分/秒、曜日の管理
  - 2つのプログラマブルアラーム
  - バッテリーバックアップ対応
  - ±5ppm 精度 (0°C～+40°C)
- **信号線**:
  - I2C: GPIO7 (SDA), GPIO8 (SCL)
  - 割り込み/SQW出力: (未接続の場合は内部処理のみ)

### 4. OV5640 カメラモジュール
- **I2Cアドレス**: 0x3C (7-bit)
- **用途**: カメラ制御（画像データはMIPI-CSI経由）
- **インターフェース**:
  - I2C: GPIO7 (SDA), GPIO8 (SCL) - 設定用
  - MIPI-CSI: CSI_A_DATA1/2, CSI_A_CLK - データ転送

## I2Cアドレス割り当て表

| デバイス | 7-bitアドレス | 8-bit (R/W) | 備考 |
|---------|--------------|-------------|------|
| ES8311 | 0x18 | 0x30/0x31 | オーディオコーデック |
| GT911 | 0x5D または 0x14 | 0xBA/0xBB または 0x28/0x29 | タッチコントローラ（設定可） |
| DS3231M | 0x68 | 0xD0/0xD1 | RTC |
| OV5640 | 0x3C | 0x78/0x79 | カメラ制御 |

## 注意事項

1. **アドレス競合なし**: 各デバイスは異なるアドレスを使用しているため競合なし
2. **プルアップ抵抗**: 基板上に実装済み（追加不要）
3. **バス速度**: 標準400kHz (Fast Mode) 推奨
4. **電源シーケンス**: デバイスによって起動時間が異なるため、初期化時に適切な待ち時間が必要
5. **DS3231M**: バッテリーバックアップ使用時は VBATピンにCR2032等を接続

## 初期化順序（推奨）

1. I2Cバス初期化 (400kHz)
2. DS3231M 初期化・時刻読み取り
3. ES8311 初期化・コーデック設定
4. GT911 初期化・タッチ設定
5. OV5640 初期化（カメラ使用時）

## Rustでの実装例（esp-idf-hal）

```rust
use esp_idf_hal::i2c::*;
use esp_idf_hal::prelude::*;

// I2Cバス初期化
let i2c = I2cDriver::new(
    peripherals.i2c0,
    sda_pin,
    scl_pin,
    &I2cConfig::new().baudrate(400_000.Hz()),
)?;

// デバイスアクセス例
const DS3231_ADDR: u8 = 0x68;
let mut time_buf = [0u8; 7];
i2c.read(DS3231_ADDR, &mut time_buf, BLOCK)?;
```
