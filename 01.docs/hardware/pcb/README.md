# PCB v1: MCP23017ベース（検証用）

JC4880P443にスピーカとバッテリ、RTCを接続してハンディBTキーボードを作る。
以下のような機能を持つ。

機能
BTキーボード
　フリック入力、半角英数の普通のキーボード
BTマウス
　キーボードの上のエリアがタッチパネルとして機能する。
　タッチパネルはSDカードから画像jpg,動画mjpegを読み込むことが可能
　読み込む画像は設定から変更可能
　タップでクリック、二本指でスクロール

BT全般
　5つの接続先を保存可能
　設定で接続先をドロップボックスで選択可能
　設定の削除ボタン、接続ボタンを設定画面に設置。
　設定が存在しないとき、接続ボタンを押すことでペアリングモード。
時計モード
　デジタル表示、アナログ表記の二つのスクリーンが設定で変更可能
　どちらも背景にSDカードから画像jpg,動画mjpegを読み込むことが可能
　アラーム音をMP3などの形式で設定可能
　これらの背景やアラーム音は設定から変更可能
　NTPで正確な時刻合わせが可能
　
PCの電源ON
　Wifiでローカルネットワークへ接続
　指定したmacアドレスに起動用のマジックパケットを送信する。
　Wifi接続が設定可能検出したSSIDから接続先、パスワードを入力し接続を行う。
　MACアドレスも指定するための設定が設定画面にある。

　~~matterを利用.このデバイスから命令を出してSwitchBot hub2に登録されたライトをつけたり消したりする。~~
　~~natterの設定用のコードはコンパイル時にコンフィグでセット~~

microsd関連
　フォーマットできる。
　USBマスストレージクラスとしてマウントできる。
　設定画面に操作可能。
