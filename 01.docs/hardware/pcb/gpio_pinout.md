# GPIO ピン接続と用途

## ピンヘッダ接続サマリー


### 既存I2Cバス（内部専用、ピンヘッダから引き出さない）

| 項目 | 仕様 |
|------|------|
| **SDA** | GPIO7（I2C_SDA） |
| **SCL** | GPIO8（I2C_SCL） |
| **接続デバイス** | タッチパネル(GT911)、DS3231 RTC（外付け追加）、ES8311オーディオコーデック、カメラ(OV5640)等 |
| **用途** | 製品内部の周辺デバイス通信専用 |
| **ピンヘッダ** | 引き出されているが外部接続しない |

**注意**: このI2Cバスはディスプレイモジュール内蔵のタッチパネル等、製品内部のデバイスとの通信に使用されます。DS3231 RTCは外付けでこのバスに追加します。MCP23017（キーボード用）とは別の新規I2Cバス（GPIO29/GPIO49）を使用します。

---

### 未接続ピン（NC）

以下のピンは本プロジェクトでは使用しない：
- **左側**: GPIO35, GPIO34, GPIO32, GPIO28
- **右側**: GPIO31, ESP_3V3, C6系ピン（U0TXD, U0RXD, IO9, CHIP_PU）

**合計NC**: 10本
